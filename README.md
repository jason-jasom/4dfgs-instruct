# Instruction Edit

## 1. Train 4D-scaffold-GS model as [here](README_4d_scaffold.mdd)

## 2. Install Instruct-4DGS packages 

Install the packages required by [Instruct-4DGS](https://github.com/CHINHUICHU/Instruct-4DGS/tree/test).

## 3. Generate edited images with Instruct-4DGS

Use Instruct-4DGS to generate edited multi-view images:

```
python ./ip2p_models/multiview_edit.py \
    --dataset "${DATASET}" \
    --scene "${SCENE_NAME}" \
    --prompt "${PROMPT}" \
    ${RESIZE_FLAG} \
    --steps 20 \
    --guidance_scale ${GUIDANCE_SCALE} \
    --image_guidance_scale ${IMAGE_GUIDANCE_SCALE}
```

The edited images can then be used as the ```--edited_images_path``` input for 4D editing.

## 4. Generate the edited video 

Generate the corresponding edited video using the workflow in ```script.sh```. Replace each placeholder with your own paths and settings:

```
python edit_3d.py \
  -m <trained model output path, e.g. outputs/DATASET/SCENE/EXP/TIME> \
  --checkpoint_dir <original 4D-GS checkpoint path, e.g. point_cloud/iteration_90000> \
  --edited_images_path <folder containing edited images from Instruct-4DGS> \
  --edited_pattern "<edited image filename pattern, e.g. edited_xxx_original_time{frame_id}_{camera_id}.png>" \
  --prompt "<edit prompt>" \
  --iterations <3D edit training iterations> \
  --save_iterations <iterations to save checkpoints>

python refine_sds.py \
  -m <trained model output path> \
  --checkpoint_dir "<checkpoint generated by edit_3d.py>" \
  --prompt "<edit prompt>" \
  --iterations <SDS refinement iterations> \
  --save_iterations <iterations to save checkpoints>

python render_edited4d.py \
  -m <trained model output path> \
  --checkpoint_dir "<checkpoint generated by refine_sds.py>" \
  --output_name <render output folder name> \
  --video_name <output video filename, e.g. edited.mp4> \
  --skip_train
```
